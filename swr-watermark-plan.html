Watermark design plan

Three concept directions, technical specs, and implementation notes for the SWR output watermark.

Purpose

Every rendered video needs a subtle watermark that:

  1. Brands the output as SWR
  2. Doesn't overpower the visuals
  3. Works at small scale (corner placement)
  4. Survives compression (TikTok/Instagram)
  5. Looks professional enough for label submissions

Design Directions (3 Concepts)

A. SWR Monogram

  • Minimal geometric "SWR" lettermark
  • Thin lines, slightly distressed or clean
  • Position: bottom-right corner, 8-12% width
  • White or inverse color based on background
  • Optional: subtle glow or outline for readability

B. Sainted Word Wordmark

  • "SAINTED WORD" in a condensed sans or custom display font
  • "RECORDS" in smaller tracking below or beside
  • Position: bottom edge, centered or right-aligned
  • More legible, less abstract than monogram

C. Icon + Text Hybrid

  • Small cross/wave/eye icon (4-6 words of symbolism)
  • "SWR" or "SAINTED WORD" beside it
  • Best for full-screen watermark or intro/outro card

Technical Specs

  • Format: PNG with transparency
  • Size: 512×512px source, scaled in CSS/overlay
  • Placement: CSS position: absolute; bottom: 24px; right: 24px; opacity: 0.6;
  • Animation: subtle fade-in at 2s, never pulse or bounce
  • Safe area: stays within 90% frame bounds (TikTok UI chrome)

Implementation

The watermark will be added in two places:

  1. Engine rendering — CSS overlay in the HTML renderer, captured by Puppeteer recording
  2. Post-production fallback — ffmpeg overlay for any manually edited renders

Deliverables

  • 3 concept designs as PNG
  • CSS snippet for engine integration
  • ffmpeg command for post-render watermarking
