The language, as data

Eight rules, no exceptions.

Console is a constrained vocabulary. The rules below are non-negotiable — break one and it stops being Console.

Background
#0A0A0B — pure black, no gradients, no atmospheric haze.
Accent
#FF6B1A — single accent, used for signal, beat, and HUD text.
Type
JetBrains Mono on canvas. Inter for UI. Fraunces for headings.
Primitives
Lines, dots, grids, bars, sine waves, rectangles. No particles, no glow, no chromatic aberration.
Beat response
Single full-frame flash, 50 ms in, 150 ms decay. No bloom, no smear.
Layer cap
3 layers visible at once. 1 hero + 1 waveform + 1 number overlay.
Data overlay
BPM, KEY, and WAVEFORM visible at all times — even with no audio loaded.
Output
Same .mp4 export, same .swr-set save format. Switch versions without re-rendering.
Why these rules

Restraint is the design.

  1. 01
    One accent only.

    Console is a signal, not a celebration. The orange is the trace. Adding a second color makes it look like every other visualizer.

  2. 02
    Pure black background.

    No gradients, no warmth, no atmospheric haze. The canvas is a control surface, not a mood.

  3. 03
    Geometric primitives only.

    Lines, dots, grids, bars, rectangles, sine waves. Particles, glow, and grain belong to other versions.

  4. 04
    Mono numerics on canvas.

    JetBrains Mono, 11–14 px, in the accent color. Tiny numbers tick next to reacting elements — like a real oscilloscope.

  5. 05
    BPM, KEY, WAVEFORM always visible.

    The data is the design. Hide them and the language collapses.

  6. 06
    Beat response is one hard flash.

    50 ms in, 150 ms decay. No bloom, no smear, no trail. The flash is punctuation, not atmosphere.

  7. 07
    Max 3 layers visible.

    1 hero element + 1 waveform + 1 number overlay. The composition is the restraint.

  8. 08
    No atmospheric effects.

    No fog, no dust, no "energy". The canvas is a control surface, not a mood.
