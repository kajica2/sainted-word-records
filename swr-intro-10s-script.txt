# =============================================================================
# SWR · 10-second intro · Hypnotic voiceover script
# =============================================================================
# Format: Apple embedded speech commands (works with macOS `say`, iOS, AvOS,
# AVSpeechSynthesizer, and most TTS engines that respect these tokens)
#
#   [[slnc N]]      → pause for N milliseconds
#   [[emph +]]w[[emph -]]  → emphasize word
#   # comment       → ignored by TTS
#   %VARIABLE%      → string substitution at runtime
#
# Suggested voice: Samantha / Daniel (en-US, calm), or any low-mid voice.
# Suggested rate: 0.5× normal (≈180 wpm) for maximum calm. Faster if used as
# an ad spot.
#
# Total duration (incl. pauses): ~13 seconds at 0.5× rate, ~9 seconds at 0.7×.
# =============================================================================


# =============================================================================
# SESSION 1 · INDUCTION (0 – 4s) — guide the viewer into trance
# =============================================================================

[[slnc 800]]
Close your eyes. [[slnc 600]]
And listen... to the music. [[slnc 800]]
[[emph +]]Feel[[emph -]] the bass. [[slnc 400]]
[[emph +]]Feel[[emph -]] the rhythm. [[slnc 1000]]


# =============================================================================
# SESSION 2 · SUGGESTION (4 – 8s) — deliver the experiential content
# =============================================================================

Now... open your eyes. [[slnc 800]]
The song you just heard... [[slnc 600]]
is the song your audience will see. [[slnc 1000]]
Audio-reactive video. [[slnc 400]]
From your browser. [[slnc 600]]
In 48 hours. [[slnc 1000]]


# =============================================================================
# SESSION 3 · WAKENER (8 – 13s) — return to normal awareness, lock in CTA
# =============================================================================

Drop a song. Get a video. [[slnc 700]]
[[emph +]]Sainted Word Records.[[emph -]]
