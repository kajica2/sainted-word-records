# PRD-003: SOCIAL FORMATS — Phase 1

## 3.1 Overview

Expand output options beyond the current 3 ratios to cover all major platforms.

## 3.2 Requirements

### 3.2.1 Format Selector

Replace current 3-button layout with dropdown:

| Label | Resolution | Aspect | Platform |
|-------|-----------|--------|----------|
| TikTok / Reels | 1080×1920 | 9:16 | TikTok, Instagram Reels, YouTube Shorts |
| Stories | 1080×1920 | 9:16 | Instagram Stories, Facebook Stories |
| Instagram Square | 1080×1080 | 1:1 | Instagram Feed |
| Instagram Portrait | 1080×1350 | 4:5 | Instagram Feed |
| YouTube Wide | 1920×1080 | 16:9 | YouTube, Vimeo |
| Twitter / X | 1200×675 | 16:9 | Twitter, LinkedIn |
| Cinema | 1920×804 | 2.39:1 | Venue screens, cinematic |
| Custom | user-defined | any | Client-specific |

### 3.2.2 Safe Zones

Toggle overlay showing:
- **Title safe:** 80% width/height (10% margin)
- **Action safe:** 90% width/height (5% margin)
- **Center crosshair**

SVG overlay, not canvas-rendered (so it doesn't appear in export).

### 3.2.3 Dual Export

When aspect is wide (2.39:1, 16:9), option to simultaneously export:
- Full width (cinematic)
- Center crop (9:16 for social)

Draggable crop region to set vertical offset.

## 3.4 Implementation Notes

- Store last-used format in `localStorage` key `swr-format`
- Custom format: show W/H inputs, validate aspect ratio
- Canvas container uses CSS `aspect-ratio` property
- Export at native resolution, not container size

## 3.5 Acceptance Criteria

- [ ] All 8 preset formats export correctly
- [ ] Safe zones toggle visible in preview, absent in export
- [ ] Dual export generates two files when selected
- [ ] Custom format accepts any W/H up to 4096×4096
- [ ] Format persists across sessions
