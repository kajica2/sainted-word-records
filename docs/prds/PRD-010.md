# PRD-010: PRINT & STILL FRAME — Phase 8

## 10.1 Overview

Events need posters. Albums need covers. Extract hero frames from any render.

## 10.2 Requirements

### 10.2.1 Frame Grab

```javascript
function captureFrame() {
  const link = document.createElement('a');
  link.download = `swr-frame-${Date.now()}.png`;
  link.href = canvas.toDataURL('image/png');
  link.click();
}
```

### 10.2.2 Hero Frame Suggestion

Analyze all frames:
- **Energy:** sum of reactor outputs
- **Color contrast:** hue histogram variance
- **Composition:** mean bright pixel position vs. center

Suggest 3 frames. Display thumbnails with scores.

### 10.2.3 Print Export

| Format | Size | DPI | Pixels |
|--------|------|-----|--------|
| Poster | 24×36 in | 300 | 7200×10800 |
| Flyer | 8.5×11 in | 300 | 2550×3300 |
| Social Square | 1080×1080 | 72 | 1080×1080 |
| Spotify Canvas | 1080×1080 | 72 | 1080×1080 |
| Story | 1080×1920 | 72 | 1080×1920 |

### 10.2.4 Print-Safe Adjustments

Toggle: "Print mode"
- Saturation +15%
- 0.125in bleed border
- Trim/safe/bleed line overlays

## 10.3 Acceptance Criteria

- [ ] Hero frame algorithm suggests 3 visually distinct options
- [ ] Poster export at 300DPI opens in Photoshop without error
- [ ] Bleed and safe lines visible in exported PNG
- [ ] Print mode saturation boost compensates for screen-to-print
