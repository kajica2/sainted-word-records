# PRD-011: MOOD BOARD & REFERENCE — Phase 9

## 11.1 Overview

Clients say "make it feel like this." Engineers need numbers.

## 11.2 Requirements

### 11.2.1 Reference Input

Accept: image URL, image upload, hex color paste.

### 11.2.2 Feature Extraction

- Dominant hues: k-means 5 colors
- Mean saturation, mean brightness
- Contrast (Michelson)
- Edge density (Sobel filter proxy)
- Temperature (warm vs. cool hue bias)

### 11.2.3 Engine Mapping

| Reference Feature | Suggested Parameter |
|-------------------|---------------------|
| Warm temperature | warmth slider → warm |
| High contrast | intensity slider → chaotic |
| High saturation | saturation +20% |
| High edge density | motion: snap, FX: grain |
| Soft / low edge | motion: smooth, FX: blur |

One-click "Apply suggestion."

### 11.2.4 Reference Overlay

Show reference image in corner at 20% size, 30% opacity, draggable.

## 11.3 Acceptance Criteria

- [ ] Upload image → extract palette within 2 seconds
- [ ] Suggestions match reference within 2 seconds of visual inspection
- [ ] Apply suggestion updates live preview immediately
- [ ] Reference overlay position persists per session
