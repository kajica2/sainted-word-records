# PRD-007: BRAND KIT — Phase 5

## 7.1 Overview

For agencies, labels, and event producers: enforce brand consistency across all renders.

## 7.2 Requirements

### 7.2.1 Logo Upload

```html
<input type="file" id="logoUpload" accept="image/png,image/svg+xml">
```

Position presets:
- `top-left-bug` (80% W, 5% H, 15% size)
- `top-right-bug` (same)
- `center-reveal` (appears on drop, scales in)
- `end-card` (last 5 seconds)
- `watermark-tile` (subtle repeating pattern, 10% opacity)
- `none`

Size: % of canvas width. Opacity: 0–100%. Animation: `fade-in`, `scale-beat`, `persistent`, `end-only`.

### 7.2.2 Color Palette Extraction

Upload brand image/PDF. Extract dominant colors via k-means:

```javascript
function extractPalette(imageData, k=5) {
  // Sample pixels, run k-means
  // Return: {primary, secondary, accent, dark, light}
}
```

Auto-map to engine:
- `primary` → shader base color
- `secondary` → shader accent
- `accent` → beat flash / highlight
- `dark` → shadow / vignette
- `light` → particle / highlight

### 7.2.3 Brand Font Lock

If font files uploaded: auto-populate text layer font dropdown. Toggle "strict brand mode" — locks to brand fonts only.

### 7.2.4 Preset Save

Save brand-mapped preset as `brand-{client}-{date}.json`. Export with video for archival.

## 7.4 Acceptance Criteria

- [ ] Logo renders crisply at 1080p, no pixelation
- [ ] Color extraction matches brand within 5% sRGB
- [ ] Brand font loads and renders correctly
- [ ] Strict mode prevents non-brand font selection
- [ ] Saved brand preset reloads identically
