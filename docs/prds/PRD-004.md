# PRD-004: TYPOGRAPHY LAYER — Phase 2

## 4.1 Overview

Add text rendering to canvas for titles, lyrics, credits, CTAs.

## 4.2 Requirements

### 4.2.1 Text Layer System

New Layer 7: `TEXT`. Rendered to canvas (not DOM overlay).

```javascript
interface TextLayer {
  id: string;
  content: string;           // Supports \n for multi-line
  fontFamily: string;         // System or uploaded
  fontSize: number;           // 0.02–0.15 (relative to canvas height)
  color: string;              // Hex or "auto"
  position: 'top-left' | 'top-center' | 'top-right' | 
            'center' | 'bottom-left' | 'bottom-center' | 'bottom-right' | 'custom';
  x: number;                  // 0–1, if position === 'custom'
  y: number;                  // 0–1, if position === 'custom'
  animationIn: 'fade' | 'scale-beat' | 'glitch' | 'typewriter' | 'slide-left' | 'none';
  animationOut: 'fade' | 'scale-beat' | 'glitch' | 'none';
  beatTrigger: 'none' | 'kick' | 'snare' | 'onset' | 'bar' | 'manual';
  startTime: number | null;  // seconds
  endTime: number | null;     // seconds, null = always-on
  blendMode: 'normal' | 'overlay' | 'difference' | 'exclusion';
}
```

### 4.2.2 Beat-Synced Animations

Use existing `beatDetector` envelope:

| Animation | Trigger | Effect |
|-----------|---------|--------|
| `scale-beat` | kick | Scale 1.0 → 1.08, decay 200ms |
| `glitch` | snare | RGB split + x-offset, 3 frames |
| `typewriter` | bar | Reveal chars at BPM rate |
| `slide-left` | bar | Enter from left, settle |

### 4.2.3 Templates

| Template | Default Content | Default Timing |
|----------|---------------|----------------|
| Opening Title | `{artist}\n{song}` | 0s to beat 4 |
| Lower Third | `{artist}` | persistent, bottom-left |
| Lyric Highlight | user paste | full song, word sync |
| Mid-Song Break | `Live at {venue}` | 8 bars before drop |
| Closing Credit | `Directed by {name}` | final 8 bars |
| CTA End Card | `Stream Now\n{url}` | final 4 bars |

### 4.2.4 Font Upload

```html
<input type="file" id="fontUpload" accept=".woff,.woff2,.ttf,.otf">
```

Load via `FontFace` API:
```javascript
const font = new FontFace(family, await file.arrayBuffer());
await font.load();
document.fonts.add(font);
```

Store in IndexedDB. Populate dropdown.

### 4.2.5 Safe Margin Enforcement

When safe zones active: text bounding box snaps to title-safe. Auto-shrink `fontSize` if overflow detected via `measureText()`.
