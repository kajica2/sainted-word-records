# PRD-006: HOOK GENERATOR — Phase 4

## 6.1 Overview

Advertising mindset: the first 3 seconds determine everything. Auto-detect the drop and export short-form hooks.

## 6.2 Requirements

### 6.2.1 Drop Detection

Algorithm:
1. Analyze energy envelope (RMS) over time
2. Find sustained low-energy period (intro, 8+ seconds)
3. Detect first major energy spike (>2× mean of intro)
4. Validate: spike must coincide with beat, have harmonic energy increase
5. Return: `{time, confidence, energy, label}`

Manual override: user can drag playhead to set drop point.

### 6.2.2 Hook Export Presets

| Preset | Duration | Content | Use Case |
|--------|----------|---------|----------|
| Teaser | 0–3s | Build + drop hit | TikTok FYP, ad pre-roll |
| Hook | 0–5s | Build + drop + 1 bar | Instagram Reels, Shorts |
| Clip | 0–15s | Intro + drop + 8 bars | Stories, Twitter |
| Full Vertical | 0–60s | Best 60s for Stories | Instagram Stories takeover |

### 6.2.3 Auto-Caption

If text layer present: animate first line as typewriter, freeze on drop.
If no text layer: burn `{artist} — {song}` pulsing on beat.

### 6.2.4 End-Card Builder

Last 2 seconds of any export. Configure:
- Background: freeze-frame or solid color
- Line 1: "OUT NOW" / "STREAMING" / custom
- Line 2: Platform icons (Spotify, Apple, YouTube) or URL
- QR code: generated via inline QR library, links to streaming URL

```html
<div id="endCardBuilder">
  <label>End Card</label>
  <input type="text" id="endCardLine1" value="OUT NOW">
  <input type="text" id="endCardLine2" placeholder="https://...">
  <label class="toggle">
    <input type="checkbox" id="endCardQR">
    <span class="toggle-switch"></span>
    Generate QR Code
  </label>
</div>
```

### 6.2.5 Thumbnail Picker

After render, auto-suggest 3 frames:
- **Peak Energy:** highest reactor output sum
- **Color Contrast:** maximum hue variance
- **User Pick:** scrubber for manual selection

Export as PNG at current canvas resolution.

## 6.3 UI Integration

Add to Export panel, above duration selector:

```html
<div class="form-row">
  <label>Hook Export</label>
  <div class="export-presets">
    <button class="export-preset" data-hook="teaser">Teaser 3s</button>
    <button class="export-preset" data-hook="hook">Hook 5s</button>
    <button class="export-preset" data-hook="clip">Clip 15s</button>
  </div>
</div>
```

## 6.4 Acceptance Criteria

- [ ] Drop detection 85% accurate without manual override
- [ ] Teaser exports play correctly on TikTok (full-screen, no bars)
- [ ] End-card QR scannable at 1080p
- [ ] Thumbnail picker shows 3 distinct options
- [ ] All hook presets include audio sync within 1 frame
