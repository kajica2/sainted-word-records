# PRD-008: LIVE / VJ MODE — Phase 6

## 8.1 Overview

Transform SWR from a renderer into a live performance instrument.

## 8.2 Requirements

### 8.2.1 Perform Mode Toggle

```html
<div class="mode-toggle">
  <button class="mode-btn active" data-mode="edit">Edit</button>
  <button class="mode-btn" data-mode="perform">Perform</button>
</div>
```

**Edit mode:** Current UI, full controls, timeline visible.
**Perform mode:** Simplified UI, large controls, scene pads, emergency buttons.

### 8.2.2 Scene Pads

8 buttons, 2×4 grid. Each loads a full engine state: preset + library subset + text config.

```html
<div class="scene-grid">
  <button class="scene-pad" data-scene="1">
    <span class="scene-num">1</span>
    <span class="scene-name">Neon</span>
  </button>
  <!-- ... 8 total -->
</div>
```

- **Press:** instant hard cut
- **Shift+press:** crossfade over 2 beats
- **Long-press (1s):** edit scene contents

### 8.2.3 Manual Beat Tap

Spacebar or on-screen button. Tap 4 times to set BPM. LED indicator flashes on detected beat.

```javascript
let tapTimes = [];
function onTap() {
  tapTimes.push(performance.now());
  if (tapTimes.length >= 4) {
    const intervals = tapTimes.slice(1).map((t, i) => t - tapTimes[i]);
    const avg = intervals.reduce((a,b) => a+b) / intervals.length;
    const bpm = 60000 / avg;
    beatDetector.setBPM(bpm);
    tapTimes = [];
  }
}
```

### 8.2.4 Emergency Controls

| Button | Key | Action |
|--------|-----|--------|
| BLACK | B | Instant cut to black, audio continues |
| FREEZE | F | Hold current frame |
| STROBE | S | 4-frame white flash on next beat |
| RESET | R | Return to scene 1, clear effects |

### 8.2.5 External Display

Detect secondary screen via `window.screen`. Offer "Send output to Display 2."

```javascript
function openOutputWindow() {
  const win = window.open('', 'swr-output', 
    `left=${screen.width},top=0,width=${screen.width},height=${screen.height},fullscreen=yes`);
  // Sync canvas to output window
}
```

### 8.2.6 MIDI Input (Optional)

Web MIDI API. Map:
- Pads 1–8 → scenes
- Slider 1 → master intensity
- Slider 2 → blur amount
- Knobs 1–4 → palette shift

UI shows "MIDI: disconnected" until device connected.

## 8.4 Acceptance Criteria

- [ ] Switch between 4 scenes without audio glitch
- [ ] Tap BPM corrects drift within 2 beats
- [ ] Blackout returns to scene on next beat
- [ ] External display shows canvas at 60fps
- [ ] MIDI scene switching < 50ms latency
