# PRD-012: DASHBOARD — Platform Page 1

## 12.1 Overview

Post-login landing. Unified view of all projects, activity, and quick actions.

## 12.2 Requirements

### 12.2.2 Features

- **Quick Start:** New project, continue last, browse templates
- **Recent Projects:** Thumbnail grid, status badge (draft/review/approved/delivered)
- **Stats:** Monthly render count, export minutes, remaining credits
- **Activity Feed:** Exports, approvals, team member actions
- **Notifications:** Client comments, preset updates, credit low warning

## 12.3 Acceptance Criteria

- [ ] Load time < 2 seconds on 4G
- [ ] Projects searchable by name, client, date
- [ ] Stats update in real-time (local calculation)
- [ ] Notifications dismissible and persistent
