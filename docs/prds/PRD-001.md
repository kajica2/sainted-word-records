# PRD-001: EXECUTIVE SUMMARY

## 1.1 Product Vision

Sainted Word Records (SWR) is a browser-native, zero-backend, audio-reactive video engine for music visualization. The current engine (`v1.0`) provides real-time reactive composition with FFT analysis, beat detection, and WebGL/Canvas rendering. It exports WebM/MP4 for social platforms.

**The Gap:** The engine is a powerful creative tool but lacks the surrounding product infrastructure to serve professional workflows: client management, multi-format delivery, live performance control, brand safety, and team collaboration.

**The Goal:** Evolve SWR from a solo creative instrument into a **professional music video production platform** without sacrificing its core architectural principles (zero-backend, privacy-first, single-file variants).

## 1.2 Target Personas

| Persona | Role | Pain Point | SWR Solution |
|---------|------|-----------|--------------|
| **Indie Musician** | Self-releasing artist | Can't afford music video production | Free tier: drop song, get video |
| **Content Creator** | TikTok/YouTube musician | Needs 5-10 videos/week, fast | Creator tier: batch export, presets |
| **Event VJ** | Live visual performer | Resolume is €799, steep learning curve | Perform mode: browser-based VJ deck |
| **Small Label** | A&R, marketing manager | Consistent brand across artist roster | Studio tier: brand kits, team seats |

| **Wedding/Event Planner** | Special events industry | Personalized visuals for first dance, party | Custom text, brand colors, live mode |

## 1.3 Core Principles (Non-Negotiable)

1. **Zero Backend:** All processing in browser. No server render. No audio upload.
2. **Privacy First:** Song and library stay on device. IndexedDB only.
3. **Single-File Aspiration:** Engine variants run as one HTML file if needed.
4. **MIT License:** Core engine stays open source.
5. **Progressive Enhancement:** Features degrade gracefully. No hard dependencies.
