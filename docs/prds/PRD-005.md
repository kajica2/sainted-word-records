# PRD-005: EDITORIAL BRIDGE — Phase 3

## 5.1 Overview

Export beat markers and metadata for professional video editors.

## 5.2 Requirements

### 5.2.1 Beat Marker Export

After analysis, offer "Download Edit Data" button.

**JSON format:**
```json
{
  "version": "swr-edl/1",
  "song": "filename.mp3",
  "duration": 187.5,
  "bpm": 124.0,
  "key": "A minor",
  "timecode": "00:00:00:00",
  "markers": [
    {"time": 0.0, "type": "downbeat", "label": "1.1", "confidence": 1.0},
    {"time": 0.484, "type": "kick", "label": "", "confidence": 0.95},
    {"time": 1.452, "type": "snare", "label": "", "confidence": 0.92}
  ],
  "drops": [
    {"time": 32.5, "confidence": 0.94, "energy": 0.87, "label": "Drop 1"}
  ],
  "phrases": [
    {"start": 0, "end": 16, "type": "intro"},
    {"start": 16, "end": 48, "type": "build"},
    {"start": 48, "end": 80, "type": "drop"}
  ]
}
```

### 5.2.2 Premiere Pro XML

```xml
<?xml version="1.0" encoding="UTF-8"?>
<PremiereData Version="3">
  <Project Name="SWR Beat Map">
    <Sequence ID="0" Name="Song — SWR" FrameRate="30">
      <Media VideoFrameRate="30" VideoWidth="1920" VideoHeight="1080"/>
      <Track Type="Audio" TrackID="1">
        <!-- Markers as clip markers -->
        <ClipMarker Time="0.000" Name="1.1" Type="Beat"/>
        <ClipMarker Time="0.484" Name="Kick" Type="Beat"/>
        <ClipMarker Time="1.452" Name="Snare" Type="Beat"/>
      </Track>
    </Sequence>
  </Project>
</PremiereData>
```

### 5.2.3 DaVinci Resolve EDL

```
TITLE: SWR Beat Map
FCM: NON-DROP FRAME
001  AX       V     C        00:00:00:00 00:00:00:00 00:00:00:00 00:00:00:00
* MARKER: 1.1 | Beat | 0.000
* MARKER: Kick | Beat | 0.484
* MARKER: Snare | Beat | 1.452
```

### 5.2.4 Reaper Tempo Map

```
# Time (s), BPM, Marker
0.000,124.000,1.1
0.484,,Kick
1.452,,Snare
```

## 5.3 UI Integration

Add to Analysis panel:

```html
<div class="form-row mt-md">
  <label>Export for Editor</label>
  <div class="flex gap-sm">
    <button class="btn btn-sm btn-secondary" onclick="exportJSON()">JSON</button>
    <button class="btn btn-sm btn-secondary" onclick="exportPremiere()">Premiere</button>
    <button class="btn btn-sm btn-secondary" onclick="exportResolve()">Resolve</button>
    <button class="btn btn-sm btn-secondary" onclick="exportReaper()">Reaper</button>
  </div>
</div>
```

## 5.4 Acceptance Criteria

- [ ] JSON imports correctly into custom tools
- [ ] Premiere XML places markers within 1 frame at 30fps
- [ ] Resolve EDL readable without errors
- [ ] Reaper tempo map sets correct BPM
- [ ] Drop detection 90% accurate on test corpus of 50 songs
