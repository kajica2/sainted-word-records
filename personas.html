Why 6 versions of the same data

One JSON, many rooms.

The FunnelLens model

The same 8 personas will be read by indie musicians, beatmakers, label managers, and sound designers — and they'll each show up in a different mood. The Editorial register reads like a magazine feature. The Dark register reads like a terminal. The Friendly register reads like a community board. The Dashboard reads like a SaaS admin. The Brutalist reads like a file dump.

Same content, different rooms. Pick the room that fits the audience you're talking to this week.

Source of truth: personas.json in the project root. Tweak the 8 personas there and all 5 registers pick up the change on next regen.
