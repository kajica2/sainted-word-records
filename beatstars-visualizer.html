What the engine actually does

Sainted Word Records is an audio-reactive video engine in the browser. It analyses your track (beats, bands, onsets) and drives layered visuals—your clips, GIFs, and images, or generative looks—while you preview in real time. When you are happy with the frame, you record a file from the same canvas.

  • Duration: the recorder can auto-stop at 10s, 15s, 30s, 60s, the rest of the song, or when you stop manually.
  • Export sizes: YouTube 16:9 (1920×1080), square 1:1 (1080×1080), Instagram 4:5 (1080×1350), Reel/TikTok 9:16 (1080×1920).
  • Format: MP4 (H.264 + AAC) when your browser supports WebCodecs; otherwise WebM. Use REC or Export video in the transport bar.
  • Privacy: your beat is not uploaded to SWR for rendering—the graph runs locally in the tab.
  • Watermark: exports include a small SWR mark by default (invite unlock can turn it off).

Step-by-step: BeatStars preview workflow

  1. Open the engine. Go to /engine and load your type beat (MP3, WAV, M4A, FLAC, and other formats the browser can decode).
  2. Build the picture. Add a few loops or stills from your brand folder, or rely on a built-in look. Layers can react to bass, mids, treble, and beat hits.
  3. Pick a style. Use the Looks dropdown in the engine, or start from a visual language page (see below). The beatmaker persona on the homepage often starts with Grid.
  4. Set export. Next to REC, choose a size preset (16:9 is a common choice for YouTube embeds) and set duration to 15s.
  5. Record. Start playback, press REC or Export video, and wait for the download. Scrub to the hook first if you want the drop in frame one.
  6. Publish off-site. In BeatStars or Airbit, use that platform’s upload or “video URL” field for the beat. On YouTube, upload the same file as an unlisted or public preview and link it on the listing. Menus and limits change over time—use whatever video slot your dashboard offers.

BeatStars vs Airbit (honest scope)

SWR is not a BeatStars plugin and not an Airbit partner tool. It does not log into your account, sync beats, or push previews automatically. You render once in the engine, keep the MP4 on your machine, and use each marketplace’s normal media upload or external link field. If a platform only accepts a YouTube URL, upload there first, then paste the link on the beat.

FAQ

  • Is this a free beat visualizer online?

    You can use the engine in the browser without paying for a render service. Exported files carry the default SWR watermark unless you have unlocked exports. There is no per-export fee in the app itself.

  • Can I make a vertical type beat video for Reels or TikTok?

    Yes. Choose the Reel / TikTok 9:16 preset (1080×1920) before recording. The stage refits to that aspect ratio for the export.

  • What if I need exactly 15 seconds every time?

    Select 15s in the duration dropdown beside REC. Start the beat from the same point (for example the intro or the drop) so each preview feels consistent across your catalog.

  • Do you store my beats on your servers?

    Rendering does not require uploading your instrumental to SWR. Optional cloud project features are separate; this preview workflow is local-first.

  • Where do I learn more about export settings?

    The interactive how-to covers song + library + record flow. Parameter details for URL flags live on the control centre if you need developer-level toggles.
