What's measured
Per-test: FPS (avg / p50 / p95 / p99), frame time (avg / p95 / p99), jitter (stddev), A/V drift (avg / max, ms), feature jitter (choppiness), buffer fill, memory (Chrome only). Each report is scored across render, stability, and sync, then graded A+ → F.
A/V sync buffer
Auto-created · always running
Audio features are pushed at 60 Hz into a ring buffer with timestamps. The render loop samples the buffer at video time with linear interpolation, so the two clocks never have to agree — drift is measured, not assumed.
