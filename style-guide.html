SWR Design System

A single source of truth for the Sainted Word Records visual language — built from the live site, the 22 visual-language engine variants, and the service-tier marketing pages. The system is warm by default: cream surfaces, sepia-tinted ink, hot-pink as the single saturated hue. Five named visual languages (Neon, Film, Grid, Smoke, Hallucination) are treated as the system's product identity moments — vibrant, gradient, and reserved.

A browser-based audio-reactive engine. One HTML file. Five visual languages. Zero install. The system is built for that promise.

Principle 01

Warm by default, hot for moments

Cream surfaces, sepia ink, hot-pink only for product identity, the launch CTA, and the 5 visual languages. Ninety percent of the system is monochrome-warm.

Principle 02

Pills over rectangles

Every button, badge, tab, and input is full-radius. Rectangles live only in data tables, code blocks, and visual-language preview tiles.

Principle 03

Editorial over generic-AI

Fraunces (display) + Geist (body) + Geist Mono (code). The system leads with a serif hero and a generous body voice — never the AI-product sans cliché.

Usage rules

Do

Use the monogram for tight spaces (favicons, nav marks, footer corner). Use the wordmark when there's room and the label needs reading. Use current when the parent element already supplies a color via CSS color.

Don't

Recolor the monogram manually with CSS filters or background — pick the right variant. Don't mix the monogram and wordmark colors (a black monogram on a dark hero reads as a missing asset).

Do

Keep the monogram at 32–48px in the nav, 24–32px in the footer. The wordmark reads at 120px+ in marketing and 24px+ in compact UI.

Don't

Stretch, skew, or rotate the monogram more than 4°. The mark is geometrically locked. If it needs rotation, use a wrapper.

01 Brand Voice

SWR is an audio-reactive video engine that ships in 90 seconds. The voice pairs editorial confidence (Fraunces) with engineer's precision (Geist Mono).

Do

Lead with the product action: "Drop a song. Get a music video." — short, declarative, no qualifiers. Let the visual language carry the warmth.

Don't

Stack hype adjectives ("revolutionary", "groundbreaking", "next-gen") or generic AI tropes ("powered by AI", "intelligently designed").

Do

Use concrete nouns and numbers: "5 visual languages", "48-hour turnaround", "30-second MP4". Specificity is the credibility.

Don't

Bury the action. Front-load qualifiers. Three clauses in one sentence. The reader knows the model and the product — they came for the music video.

Do

Mix register — Fraunces serif for the hero and emotional moments, Geist sans for body, Geist Mono for technical surfaces. The system is multi-voiced by design.

Don't

Pick one typeface and use it everywhere. The mixture is the brand. A landing that is all-Geist reads like a SaaS dashboard, not a music engine.

Do

Talk about audio in music terms — BPM, beat, onsets, FFT bands, chromagram. The audience knows what they sound like. The system respects that.

Don't

Talk about audio in data terms — "audio data", "signal processing", "frequency analysis". That language is for spec sheets, not landing pages.

How a visual language is specified

Each language is a self-contained .swr-set JSON file with palette, motion, FX chain, and a single signature blob. The engine loads the file, swaps the WebGL uniforms, and the music video takes a new shape.

// 1 of 5 visual languages — the Neon personality
{
  "id": "swr-preset-neon-v1",
  "name": "Neon Church",
  "palette": { "a": "#ff2d8a", "b": "#00f0ff", "bg": "#0a0610" },
  "motion": "screen-blend",
  "fx":    { "chroma": 0.85, "glow": 0.6, "scanlines": 0.3 },
  "signature": "cuts-on-the-beat"
}

15 Do & Don't

The rules that hold the system together.

Do

Use cream surfaces and sepia ink for 90% of the system. Let the 5 visual languages and the launch CTA bring the color.

Don't

Apply hot-pink or orange to navigation or general UI. They're reserved for the launch CTA and the 5 visual languages.

Do

Default to pill radius (9999px) for buttons, badges, and inputs. Rectangles live only in data tables, code blocks, and the 24px product cards.

Don't

Mix a third typeface into the system. Fraunces (display) + Geist (body) + Geist Mono (code) is the trio. Adding more dilutes the brand.

Do

Use the hot-pink brand glow on hero bands, product cards, and the launch CTA. It's the system's "this is the moment" signal.

Don't

Use italics for emphasis in body text. Change weight (500, 600, 700), not slope. Fraunces is the only place italics are allowed.

Do

Keep body at 16px / 1.6. Hero display at 44–80px. Section kicker (the mono uppercase label) at 11px / 0.12em / 600.

Don't

Push the hero past 80px on desktop or below 40px on mobile. The system tunes for that band. Outside it, the typography looks uncalibrated.

Do

Talk about audio in music terms — BPM, beat, FFT, chromagram. The audience knows what they sound like. The system respects that.

Don't

Talk about audio in data terms — "audio data", "signal processing", "frequency analysis". That language is for spec sheets, not landing pages.
