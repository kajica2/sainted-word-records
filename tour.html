The 10 heuristics behind this tour
  1. H1 · visibility — keep the user informed about state.
  2. H2 · match with the real world — speak the user's language.
  3. H3 · user control and freedom — make actions reversible.
  4. H4 · consistency and standards — same words, same actions, same order.
  5. H5 · error prevention — fail before the user does.
  6. H6 · recognition rather than recall — show, don't require memorization.
  7. H7 · flexibility and efficiency — shortcuts for power users.
  8. H8 · aesthetic and minimalist design — no irrelevant info.
  9. H9 · help recognize / diagnose / recover — clear error messages.
  10. H10 · help and documentation — easy to find, task-focused.
