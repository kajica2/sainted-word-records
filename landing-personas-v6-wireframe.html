// About this register

The V6 register renders the same personas as a Three.js wireframe scene. The geometry is the only thing that changes — the data, the five character presets, the eight people below, all stay identical.

[ 01 ]

One JSON. Six renders.

personas.json is the only source. Six visual registers render it: V1 editorial, V2 dark, V3 friendly, V4 dashboard, V5 brutalist, V6 wireframe. Tweak the JSON, all six update on next regen.

[ 02 ]

3D primitives as avatars

Each persona gets its own wireframe primitive. The torus knot, the octahedron, the cone — a 3D glyph that says "this is a person, not a stock icon" without ever rendering a face.

[ 03 ]

Zero build. Pure CDN.

Three.js loads from jsDelivr. Fonts from Google. The page is a single HTML file with inline CSS, inline JSON, inline SVG favicon. Open it from disk and it works — no server, no bundler, no Vite.

// How it works

Three coordinates, three steps, one HTML file.

[ x:0 y:0 z:0 ] 01

Drop the audio

WAV, MP3, or in-app mic. The engine reads it locally, runs Web Audio analysis, no upload, no server, no permission prompt for the file picker.

[ x:1 y:0 z:0 ] 02

Pick a version

Five character presets: neon, grid, smoke, film, hallucination. Each maps a different visual register to the same audio buffer. Pick the one that fits the release.

[ x:2 y:0 z:0 ] 03

Render the MP4

MediaRecorder exports the canvas at 30fps. 15s teaser, 30s single, 60s Reel — whatever the post needs. Local file, no watermark, MIT licensed.
