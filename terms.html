Accessibility and Metadata Terms

Shape tags — use shapes instead of colors.

Example: Circle = spoken word. Square = music. Triangle = hybrid. Stripe = live. Dot = studio. Wave = remix. Diamond = archival.

Pattern tags — solid, dotted, striped, checkered, wavy.

Text tags — always write the tag name in plain text.

Color rule — never use color alone. Use shape + pattern + text.

Dyslexia-friendly layout — sans-serif font, left-aligned, 1.5 line spacing, off-white background, no all-caps, bold for emphasis.

Autism-friendly layout — predictable order, content warnings, sensory notes, quiet zones, clear schedules.

Colorblind-friendly layout — high luminance contrast, no red/green pairs, no color-only labels.
