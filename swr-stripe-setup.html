Stripe payment links setup

10-minute walkthrough: create products, generate payment links, plug them into campaign.html.

What You Need

  • Stripe account (free to create at stripe.com)
  • 5 minutes

Step 1: Create the Products

In your Stripe Dashboard → Products → Add product:

Product Name Price Description
SWR Single €25.00 1 curated set · 1 song · 30s render
SWR Double €45.00 2 curated sets · 1 song · 30s renders
SWR Full Rotation €75.00 All 5 sets · 1 song · 5 renders
SWR Custom Source €55.00 Your assets + 1 SWR set · 30s render

Set each to One-time payment. No shipping, no tax.

Step 2: Generate Payment Links

For each product, click "Create payment link" in the product detail page.

Configure:

  • After payment: Redirect to https://sainted-word-records.vercel.app/thanks.html
  • Collect: Customer email (required — this is how you know who paid)
  • Collect: Phone number (optional)
  • Allow promotion codes: Yes (for founding-customer discounts)

Step 3: Copy Links Into campaign.html

Replace the placeholder URLs in campaign.html:


https://buy.stripe.com/SWR_SINGLE_25   → your real Single link
https://buy.stripe.com/SWR_DOUBLE_45   → your real Double link
https://buy.stripe.com/SWR_FULL_75     → your real Full Rotation link
https://buy.stripe.com/SWR_CUSTOM_55   → your real Custom Source link

Step 4: Test Mode

Before going live:

  1. Toggle Stripe to Test mode (top-right switch)
  2. Use test card 4242 4242 4242 4242, any future date, any 3-digit CVC
  3. Complete a test purchase
  4. Verify the redirect and email collection work
  5. Switch to Live mode and repeat with real card

Step 5: Fulfillment Workflow

Stripe sends you an email for every purchase. Your workflow:

  1. Receive payment email from Stripe (contains customer email)
  2. Email the customer within 2 hours:
Hi [name], thanks for ordering SWR [Single/Double/Full/Custom]. Send me: - Your song (WAV or MP3, WeTransfer/Drive/Dropbox link) - Which set(s) you want [Neon Church / Morning Haunt / Brutalist Grid / Dream Sequence / System Error] - Preferred format [9:16 / 1:1 / 16:9] - Any reference videos or notes I'll confirm delivery time within 24 hours.
  1. Render using the engine at http://localhost:5174/
  2. Deliver via WeTransfer or Google Drive
  3. Follow up 48 hours after delivery asking if they need revisions

Founding Customer Discount (30% Off)

Create a promotion code in Stripe for each product:

Product Code Discounted Price
Single FOUNDER1 €17.50
Double FOUNDER2 €31.50
Full FOUNDER3 €52.50
Custom FOUNDER4 €38.50

Set each code to:

  • Type: Percentage off
  • Amount: 30%
  • Redemption limit: 2 (only 2 uses per code = 8 total founding slots)
  • Expiration: 30 days from now

Mention these codes in your founding-customer outreach. First come, first served.

Alternative: Lemon Squeezy (EU-friendly)

If Stripe isn't available in your country or you want EU VAT handling:

  1. Sign up at lemonsqueezy.com
  2. Create products with the same names/prices
  3. Generate checkout links
  4. Replace Stripe URLs in campaign.html with Lemon Squeezy checkout URLs
  5. Lemon Squeezy auto-handles EU VAT + sends license keys — less manual work

Automation (Optional, Month 2+)

When order volume justifies it, automate:

  • Zapier/Make: Stripe payment → Send email with form link (Typeform/Tally)
  • Form: Collects song link, set choice, format preference
  • Airtable/Notion: Track order status (Paid → Assets Received → Rendering → Delivered)
  • Zapier: Airtable status change → Email customer with Drive/WeTransfer link

Don't build this until you've processed 20+ orders manually. The manual phase teaches you what questions customers actually ask.

Setup time: 10 minutes. Revenue starts when the first link is live.
